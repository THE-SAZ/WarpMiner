# Contributing • مشارکت

Thanks for considering a contribution! 🙏

1. 🍴 Fork the repo
2. 🌿 Create a branch: `git checkout -b feature/my-idea`
3. ✍️ Make your change (keep the single-file spirit of `index.html`)
4. 🧪 Test in a modern browser (mobile + desktop)
5. 🔀 Open a Pull Request with a clear description

**Bug reports:** open an Issue with browser name/version, steps to reproduce and a sample (sanitized) sub format if possible.

---

از مشارکت شما سپاسگزاریم! برای گزارش باگ یک Issue باز کنید و برای افزودن قابلیت، Pull Request بفرستید.
