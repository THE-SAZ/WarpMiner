# Security Policy

---

**Please do not open public issues for security vulnerabilities.**
Report privately via a private Issue or contact the maintainer directly.

Supported versions: `1.x`

# سیاست امنیتی

---

لطفاً حفره‌های امنیتی را به‌صورت عمومی ثبت نکنید؛ از طریق Issue خصوصی به اطلاع سازنده برسانید.
