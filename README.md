# 🇬🇧 English

## ✨ What is WarpMiner?

**WarpMiner** is a single-page, offline-first **Progressive Web App (PWA)** that generates
[AmneziaWG](https://amnezia.org/) configs compatible with **Cloudflare WARP**. It is engineered
around a battle-tested "golden formula" so the generated configs connect **instantly** in the
Amnezia app — no endless "Connecting…" spinner.

> ⚠️ **Important:** WarpMiner **only** outputs the **AmneziaWG** format. It never produces plain
> WireGuard or any other protocol, because AmneziaWG's obfuscation layer is what makes WARP
> traffic resilient under DPI.

## 🌟 Key Features

| Feature | Description |
|---|---|
| 🛡 **Golden Formula** | `S1=0, S2=0`, `H1=1..H4=4`, `Jc=8, Jmin=55, Jmax=140` — tuned for instant handshake |
| 🔢 **Protocol Versions** | Supports AmneziaWG **v1.5**, **v2.0** and **v3.1** (adds `S3`/`S4`, magic packets `I1–I5`) |
| 📦 **IP Vault** | 18 tools: add, search, filter-by-port, sort, shuffle, dedupe, star, import/export, 3 save slots |
| ⚡ **Auto Select** | One-tap picks a random endpoint from the vault straight into the target field |
| 💎 **Bulk Forge** | Generate up to **10 configs at once**, each with its own QR code |
| 🖼 **Offline QR Engine** | A full QR generator written in pure JS — **zero CDN dependency**, works everywhere |
| 🔐 **Auto Key Generation** | The private key is created automatically before forging — you never hit a "missing key" error |
| 🌀 **Warp-in-Warp** | Double-layer tunneling with duplicate-endpoint protection |
| 🌍 **Trilingual UI** | فارسی / English / Русский with full RTL support |
| 📴 **Offline PWA** | Service Worker caches the app shell — runs with **no internet** after first load |
| 🎨 **4 Soft Themes** | Violet, Ocean, Sunset, Forest — easy on the eyes |

## 📖 Usage Tutorial

1. **Open WarpMiner.** The IP Vault loads with 87 pre-seeded Cloudflare endpoints.
2. **Choose a target endpoint.** Either click the ⚡ **Auto Select** button, press 🎲 random, or use
   the 🎯 target icon on any row in the vault.
3. **Pick a protocol version** — `v1.5`, `v2.0` or `v3.1`.
4. **Pick an output mode:**
   - 🛡 **Anti-filter** (default): adds obfuscation params for DPI-heavy networks.
   - ⚡ **FAST (WARP)**: minimal params for maximum speed.
5. **Press ⚒ Forge.** WarpMiner auto-generates the private key if needed, builds the config, runs a
   sanity check, and shows the result with a **SANITY: PASS** badge.
6. **Copy, download, or scan.** Use 📋 Copy, 💾 `.CONF`, or 🖼 **QR Code**.
   Scan the QR directly from the Amnezia app's import screen.
7. **Bulk Forge** (💎) builds up to 10 configs at once from your selected endpoints — each with QR.

## 🧠 The Golden Formula Explained

```
[Interface]
PrivateKey = <auto-generated>
Address    = 172.16.0.2/32, 2606:4700:110:.../128
DNS        = 8.8.8.8
MTU        = 1280
Jc = 8            ← junk packet count
Jmin = 55         ← min junk size
Jmax = 140        ← max junk size
S1 = 0            ← init padding
S2 = 0            ← response padding
H1 = 1            ← init header
H2 = 2            ← response header
H3 = 3            ← underload header
H4 = 4            ← transport header

[Peer]
PublicKey = bmXOC+F1FxEMF9dyiK2H5/1SUtzH0JuVo51h2wPfgyo=
AllowedIPs = 0.0.0.0/0, ::/0
Endpoint   = <chosen endpoint>
PersistentKeepalive = 25
```

This exact combination is what avoids the dreaded **"Connecting…" stuck state** in the Amnezia app.

## 🛠 Development & Setup

```bash
# Clone the repository
git clone https://github.com/THE-SAZ/warpminer.git
cd warpminer

# (one-time) Generate the PNG icons:
#   open tools/icon-generator.html in a browser and click "Download All",
#   then move the files into assets/

# Serve locally (any static server works)
python -m http.server 8080
# → http://localhost:8080
```

### Deploy to GitHub Pages
1. Push the repo to GitHub.
2. Go to **Settings → Pages → Source: main branch / root**.
3. Ensure an empty `.nojekyll` file exists at the repo root.
4. Your site goes live at `https://<username>.github.io/<repo>/`.

## 🔒 Privacy

- **No servers, no tracking.** Everything runs in your browser.
- Keys are generated **locally** with the Web Crypto API.
- All data (vault, settings, keys) stays in your browser's `localStorage`.

# 🇮🇷 فارسی

## ✨ وارپ‌ماینر چیست؟

**وارپ‌ماینر** یک **وب‌اپ پیش‌رو (PWA)** تک‌صفحه‌ای و آفلاین است که کانفیگ‌های
[AmneziaWG](https://amnezia.org/) سازگار با **کلادفلر وارپ** می‌سازد. هستهٔ برنامه بر پایهٔ
«فرمول طلایی» آزمایش‌پس‌داده ساخته شده تا کانفیگ‌ها **فوراً** در اپلیکیشن Amnezia متصل شوند —
بدون گیر کردن روی «در حال اتصال…».

> ⚠️ **نکته:** وارپ‌ماینر **فقط** خروجی **AmneziaWG** تولید می‌کند و هرگز WireGuard خالص یا
> پروتکل دیگری نمی‌سازد؛ چون لایهٔ استتار AmneziaWG همان چیزی است که ترافیک وارپ را در برابر
> فیلترینگ مقاوم می‌کند.

## 🌟 قابلیت‌های کلیدی

| قابلیت | توضیح |
|---|---|
| 🛡 **فرمول طلایی** | `S1=0, S2=0` و `H1=1..H4=4` و `Jc=8, Jmin=55, Jmax=140` برای اتصال فوری |
| 🔢 **نسخه‌های پروتکل** | پشتیبانی از **v1.5**، **v2.0** و **v3.1** (با `S3`/`S4` و پکت‌های جادویی `I1–I5`) |
| 📦 **مخزن آی‌پی** | ۱۸ ابزار: افزودن، جستجو، فیلتر پورت، مرتب‌سازی، بر زدن، حذف تکراری، ستاره، ایمپورت/اکسپورت، ۳ اسلات |
| ⚡ **انتخاب خودکار** | با یک کلیک، یک اندپوینت تصادفی از مخزن وارد فیلد هدف می‌شود |
| 💎 **فورج انبوه** | ساخت تا **۱۰ کانفیگ هم‌زمان**، هرکدام با QR اختصاصی |
| 🖼 **موتور QR آفلاین** | تولیدکنندهٔ QR کاملاً جاوااسکریپتی — **بدون هیچ CDN**، همه‌جا کار می‌کند |
| 🔐 **تولید خودکار کلید** | کلید خصوصی قبل از ساخت به‌صورت خودکار ساخته می‌شود — هرگز خطای «کلید نداریم» نمی‌گیرید |
| 🌀 **وارپ در وارپ** | تونل دولایه با محافظت در برابر اندپوینت تکراری |
| 🌍 **رابط سه‌زبانه** | فارسی / انگلیسی / روسی با پشتیبانی کامل راست‌به‌چپ |
| 📴 **آفلاین کامل** | سرویس‌ورکر پوستهٔ اپ را کش می‌کند — پس از بار اول **بدون اینترنت** کار می‌کند |
| 🎨 **۴ تم ملایم** | یاسی، اقیانوس، غروب، جنگل |

# 🇷🇺 Русский

## ✨ Что такое WarpMiner?

**WarpMiner** — это одностраничное офлайн-**прогрессивное веб-приложение (PWA)**, которое создаёт
конфиги [AmneziaWG](https://amnezia.org/), совместимые с **Cloudflare WARP**. Ядро построено на
проверенной «золотой формуле», поэтому конфиги подключаются **мгновенно** — без бесконечного
«Подключение…».

> ⚠️ **Важно:** WarpMiner создаёт **только** формат **AmneziaWG** и никогда не генерирует обычный
> WireGuard или другие протоколы.

## 🌟 Ключевые возможности

| Функция | Описание |
|---|---|
| 🛡 **Золотая формула** | `S1=0, S2=0`, `H1=1..H4=4`, `Jc=8, Jmin=55, Jmax=140` |
| 🔢 **Версии протокола** | **v1.5**, **v2.0** и **v3.1** (`S3`/`S4`, магические пакеты `I1–I5`) |
| 📦 **Хранилище IP** | 18 инструментов: добавить, поиск, фильтр по порту, сортировка, перемешать, убрать дубли, избранное, импорт/экспорт, 3 слота |
| ⚡ **Авто-выбор** | Одним нажатием случайный эндпоинт попадает в поле цели |
| 💎 **Массовая сборка** | До **10 конфигов сразу**, каждый со своим QR |
| 🖼 **Оффлайн QR-движок** | Полностью JS-генератор — **без CDN**, работает везде |
| 🔐 **Авто-ключ** | Приватный ключ создаётся автоматически перед сборкой |
| 🌀 **Warp-in-Warp** | Двухслойный туннель с защитой от дублей |
| 🌍 **Три языка** | فارسی / English / Русский с поддержкой RTL |
| 📴 **Оффлайн** | Service Worker кеширует приложение — работает **без интернета** |
| 🎨 **4 темы** | Фиолетовая, Океан, Закат, Лес |
